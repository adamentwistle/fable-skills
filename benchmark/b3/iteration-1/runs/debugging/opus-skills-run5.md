1. **Root cause:** the cache has an initialization guard, not an invalidation policy — `_cache is None` is only ever true once per process, so disk changes can never be seen; fix by recording the file's identity stamp (`os.stat` → `st_mtime_ns`, `st_size`, `st_ino`) alongside the data and reloading when the stamp differs.
2. **Second bug:** one global slot is shared across all `path` values, so the first caller's file is returned to every other caller forever; fix by keying the cache dict on the resolved absolute path.
3. `st_mtime_ns` alone can miss a write that lands in the same filesystem tick on a coarse-granularity volume; fix by comparing the `(mtime_ns, size, inode)` triple, or hashing contents when correctness matters more than the stat cost.
4. The reload is not atomic against a concurrent writer, so a partial file raises `json.JSONDecodeError` and, worse, a raise mid-assignment can leave the cache half-updated; fix by parsing into a local and swapping the reference only on success, keeping the previous value on failure.
5. Concurrent first-callers can each open and parse the file and race on the global assignment; fix with a module-level `threading.Lock` around the stat-check-and-reload block.
6. **Not a fix — TTL/expiry:** it only bounds how long you serve stale data instead of removing the staleness, and it re-reads when nothing changed; it is a mitigation, not the cause.
7. **Not a fix — `functools.lru_cache`:** its entries are equally permanent, so it reproduces the exact bug with less visible code, and `maxsize` eviction is not change detection.
8. **Not a fix — `if not _cache`:** it makes an empty-but-valid `{}` config reload every call while a populated one stays stale forever; it swaps one wrong condition for another.
9. **Not a fix — dropping the cache and reading every call:** it does end the staleness but discards the caching the function exists to provide, and each call now pays parse cost plus a new failure mode when the file is briefly unreadable.
10. **Not a fix — an explicit `clear_config_cache()` for call sites:** it puts correctness in the hands of every caller and still returns stale data whenever an external process edits the file.
